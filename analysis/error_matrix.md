## Spec gaps closed in this phase (tests exposed → minimal fixes)

1. **Typed mic-start errors** — `MicNotFound`/`MicBusy` raised by `source.start()` were wrapped as "Unexpected background error"; the controller now emits typed ERROR events so the GUI can show the prd-mandated plain messages (`controller.py`).
2. **Model-missing Start-disable** — prd requires Start disabled when the model is missing; the GUI now disables Start on `error_type == "ModelMissingError"` while keeping Undo/Reset usable (`gui/app.py`).
3. **Consecutive recognition-failure stop** — `MAX_CONSECUTIVE_RECOGNITION_ERRORS = 5` existed in `config.py` but was never enforced; the controller now stops the session after 5 consecutive `ASR_ERROR` decisions, with the counter resetting on any successful/other decision (`controller.py`).
